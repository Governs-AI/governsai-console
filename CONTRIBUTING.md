# Contributing to GovernsAI Console

## Setup

```bash
pnpm install
pnpm generate
```

## Development

```bash
pnpm dev:platform
```

## Validation

```bash
pnpm lint
pnpm check-types
pnpm build
```

## Pull Request Checklist

- Keep changes scoped and atomic.
- Add tests for behavioral changes.
- Update docs for API or UX changes.
- Use clear commit messages.
